# Changelog

## 1.0.0 - 2026-10-20

First public release of Gang of Four in Action.

- Includes the deliberately messy CornerStore baseline with 23 catalogued code smells.
- Includes 23 standalone pattern solutions, each refactoring one baseline seam, and a capstone that combines all 23 patterns.
- Adds a pattern comparisons guide for commonly confused patterns.
- CI restores, builds and tests the umbrella solution, then verifies that pattern diffs match the baseline.
